# Sources and scope

Core reproduction by JinglangQiu (GitHub: jinglangqiu-hub), with Codex assistance for implementation checks, tooling, report preparation and publication.

- Original paper: Kipf & Welling, ICLR 2017, [arXiv v4](https://arxiv.org/abs/1609.02907v4).
- Reference implementation: [tkipf/gcn](https://github.com/tkipf/gcn/tree/39a4089fe72ad9f055ed6fdb9746abdcfebc4d81), MIT, Thomas Kipf (2016). Its notice is retained in `licenses/tkipf-gcn-MIT.txt` for adapted preprocessing/protocol logic.
- Cora/Planetoid-format data are downloaded from that pinned reference revision, with original byte hashes. The software MIT license does not grant additional rights to third-party datasets or the paper. Cite the dataset sources described in the upstream README and paper.
- This is a third-party Cora core reproduction, not the authors' official implementation or a full reproduction of all paper experiments.
